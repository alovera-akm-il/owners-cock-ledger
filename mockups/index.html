The Ledger — UI Mockups

Static HTML/Tailwind/jQuery mockups. Placeholder data throughout; no real content or images.

Shared

  • login.html — sign in / invite redemption / forgot-password request entry point
  • reset-password.html — where the emailed reset link lands; set a new password

Keyholder

  • keyholder-dashboard.html — roster, stats, safety-alert banner
  • submissive-detail.html — per-submissive status, policy, review queue, activity
  • proof-review.html — verify / redo / fail, with punishment picker
  • catalog.html — tasks, rewards & punishments catalog, with success/failure escalation and points
  • keyholder-toy-catalog.html — toy inventory: full CRUD, pending retirement requests
  • checkin-templates.html — check-in template builder: color, dynamic fields, auto-escalate-on-RED toggle
  • play-session-templates.html — reusable session shapes, assign flow, recent sessions
  • play-session-detail.html — live/retrospective session, check-in schedule, judgement panel
  • checkin-live.html — side-by-side demo of the real-time live check-in channel
  • keyholder-points-and-redemptions.html — per-submissive point balances, ledgers, redemption request queue
  • keyholder-profile.html — credentials, hard/soft limits, API token management
  • keyholder-audit-log.html — cross-roster audit trail: who did what, session vs API token vs system
  • keyholder-safety-alerts.html — acknowledge/resolve queue, sorted by urgency
  • keyholder-submissive-statistics.html — read-only view of one submissive's stats, same shape they see

Submissive

  • submissive-dashboard.html — own status, current code, open items, safety alert
  • submit-proof.html — code display + photo/video/voice proof upload form
  • submit-checkin.html — fill in a standalone/task-attached check-in (not live)
  • submissive-toy-catalog.html — own toy inventory: add freely, request removal
  • submissive-play-sessions.html — own assigned/live/past sessions
  • submissive-play-session-detail.html — start/end a session, log check-ins, read-only judgement once decided
  • submissive-rewards.html — points balance, redeemable rewards, ledger history
  • submissive-history.html — own verification & assignment history
  • submissive-profile.html — credentials, safeword, hard/soft limits, view Keyholder's limits
  • submissive-statistics.html — streak, consistency, session lengths, compliance, punishments/rewards, lifetime totals
